📱 SpiceMobile – IT Asset & Inventory System

Sistem integrat Client Mobil + Server Java Desktop pentru gestiunea inventarului IT

SpiceMobile este o soluție software creată pentru digitalizarea și automatizarea fluxurilor de inventariere IT. Aplicația mobilă le permite tehnicienilor scanarea rapidă a echipamentelor prin coduri de bare, QR și cipuri NFC/RFID, comunicând direct prin socket-uri TCP/IP pe portul 5000 cu serverul centralizat de gestiune (SpiceMobileServer) și baza de date SQLite.

Android Studio / Java Eclipse Workspace (Server) SQLite Database (`pv.db`) NFC / RFID Tag Programming Google Lens / Camera Barcode Auto Backup Engine

🖥️ Server Centralizat & Consolă Live (SpiceMobileServer)

Consolă administrare server: Configurare căi DB/Backup, sistem de retenție fișiere, driver binar injectat și asistență conexiuni live pe portul 5000.

📲 Interfață Client Mobil (SpiceMobile App)

1. Autentificare Tehnician

2. Meniu Identificare Asset

3. Navigation Drawer

4. Interogare Server Live

5. Scanare Optică (Camera Lens)

6. Înregistrare & Scriere Tag RFID

7. Monitorizare Progres Sesiune

8. Pop-up Validare Stare Asset

9. Registru Procese Verbale

📊 Generare Rapoarte & Export Inventar

Raport generat automat în urma auditului: marcare status echipamente (SCANAT_FIZIC / NESCANAT), identificare locație, tehnician responsabil și timestamp exact.
