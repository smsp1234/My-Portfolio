Java + Android Ecosystem

Java SDK Android Studio TCP/IP Sockets

Prezentare Generală

Un sistem distribuit complex care integrează un server central de banking cu o aplicație de gestiune a unei librării, totul fiind accesibil și sincronizat în timp real pe dispozitive mobile Android.

Detalii Tehnice

- Arhitectură Client-Server bazată pe porturi dedicate (5000-5003).
- Comunicare bidirecțională prin socket-uri TCP/IP.
- Portarea logicii de desktop pe Android folosind procese asincrone pentru stabilitate.
- Gestiunea tranzacțiilor financiare și a bazei de date a librăriei.
